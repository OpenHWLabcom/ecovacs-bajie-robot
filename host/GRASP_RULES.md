# 抓取桌面物体铁律（2026-10-19 管理员定）

1. **第一步必须先升高立柱**：任何抓取桌面物体的动作，开始前先把升降立柱升到安全高度，使机械臂基座/夹爪高于桌面；禁止低立柱状态直接前伸抓桌面。
2. **先到预备位置，且夹爪必须高于桌面**：抓取前夹爪先到目标上方的预备位置（建议 ≥ 桌面 + 12cm），只允许**从上往下（top-down）**接近；禁止从下往上、从桌沿下掏或贴桌面横扫。
3. **定位顺序**：头部相机先找目标 → 手腕（夹爪）相机精定位 → 再执行抓取。
4. **不碰桌面**：抓取/移动过程中夹爪摄像头和指尖不得接触桌面；下降只允许在目标正上方、且指尖保持在桌面以上安全距离（≥1cm，优先 ≥2cm）。
5. 任何前伸/大范围运动前，仍必须先走侧摆A，离立柱 ≥6cm；不满足即中止。
