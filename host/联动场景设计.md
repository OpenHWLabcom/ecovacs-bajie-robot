# 机器人 ⇄ 无人机 联动场景设计（2026-10-11）

> 现状：**机器人可指令控制**（走/转/升降/头/臂/相机/语音/回充/导航 + 状态回传）；
> **无人机（DJI Mini 3 Pro + RM330）不可程序指挥**——协议闭源，只能「**拍屏画面 + OCR 读屏**」（高度/速度/距离/电量/GPS/状态）。
> ⇒ 现阶段"联动"= **机器人侧全自动 + 无人机侧人工（我们给提示/把信息喂给人）**；若要全自动需换**行业机 + 上云 API**。

## 一、联动三根"线"
1. **机器人 → 人/无人机**：机器人事件（到位 / 低电 / 告警 / 任务完成）→ 控制台弹提示·手机推送·机器人语音 → 提示操作员起飞。
2. **无人机 → 机器人**：拍屏 OCR（GPS/高度/速度/电量/状态词）→ 人工确认 → 一键触发机器人动作（去某点 / 转头 / 举手 / 喊话）。
3. **共享"眼"与"景"**：控制台同屏放 **机器人SLAM地图 + 机器人头/臂相机 + 无人机画面**；目标点用「📌 标记」放到机器人地图上。

## 二、场景（按"现在能不能做"排序）

### ① 空地协同巡检 ★推荐首发
无人机空中俯视巡逻 → 拍到目标（人/车/火/异常）→ 操作员在控制台点「📌 标记目标」→ **八界自动导航到该点**地面核实（头部相机对准 + 语音"我到现场了"）。
- 联动：无人机画面/OCR → 标记点 → 机器人 `navigation`。
- 现在能做：机器人 ✅ ｜ 无人机人工飞 ✅ ｜ 缺口：无人机 GPS→机器人SLAM 无直接换算，需**人工点选/标定**。

### ② 机器人发现异常 → 呼叫无人机空中复核
机器人下视/撞板/相机识别异常（或 `alarm`）→ 控制台弹「⚠️ 建议空中复核」→ 操作员起飞；同时机器人 `wave_hand_ctrl` **举手当视觉标记**方便空中定位。
- 联动：机器人事件 → 提示 + 举手 + 语音"需要空中支援"。
- 现在能做 ✅（"事件→提示/举手"是新逻辑，简单）。

### ③ 无人机引导地面（一个操作员同时"看天+开地"）
无人机俯视找目标 → 操作员边看无人机画面、边用控制台**虚拟摇杆开机器人过去** → 到位语音回报。
- 联动：双画面同屏（无人机 + 机器人相机）+ 一个摇杆控机器人。
- 现在能做 ✅（界面已有；加个"并排大屏"模式即可）。

### ④ 起降 / 换电协同（机器人当"移动机场"）
机器人驮无人机（或降落垫/备用电池）到户外起降点 → 起飞 → 返回时机器人已在位 → 臂+高度**接住/换电/收纳**。
- 现在能做：机器人移动+臂+高度 ✅；无人机起降人工 ✅；夹取需实测（臂力/尺寸）。

### ⑤ 搜索救援（人找人）
无人机大范围扫 → 疑似人员 → 操作员标记 → 机器人到附近 → 头部相机近距确认 + 语音安抚/播报坐标。
- 同 ①，侧重"确认"环节。

### ⑥ 巡逻接力 / 视野互补
机器人在室内（SLAM）巡逻，无人机在户外（空中）巡航；谁先发现异常就通知另一方。
- 现在能做：机器人巡逻=跑航点 ✅；无人机人工 ✅；同一块屏看两边。

### ⑦ 送物"最后一公里"
无人机短途送小件 → 机器人接收（臂）→ 室内送达。（无人机投送需挂载，较复杂。）

### ⑧ 应急/夜间协同
无人机照明/喊话 + 机器人地面执行（机器人自带**消毒灯**、语音播报）。

### ⑨ 展会/直播演示 ★最易出效果（面向 OpenHW Lab 官网/展会）
"八界"在地面讲解/挥手，无人机空中环绕，控制台一块屏展示**空地一体的画面与数据** → 官网 demo 视频素材。
- 现在能做 ✅（机器人动作+语音+双画面已具备）。

## 三、要落地的"联动引擎"（控制台加「🔗 联动」面板）
**规则 = 触发 → 动作**（可增删、可手动一键）：
- **触发源**：机器人（到达点 / 低电 / `alarm` / 任务状态变化 / 相机识别命中）· 无人机（OCR：高度>X / 电量<Y / 出现"未登录/返航/GPS"等关键字）· 手动按钮 · 定时。
- **动作**：机器人（去点 / 停 / 转头 / 举手 / 臂动作 / 升降 / 语音）· 提示（控制台弹窗 / 手机推送 / 语音播报）· 记录（地图打点 / 写事件流）。
- **共享事件流 + 地图标记**：机器人 SLAM 图上放"无人机标记/目标点"。

## 四、建议的第一步（最小可用）
1. 控制台加 **「📌 标记目标」**（在地图上点一个点）→ 一键让机器人 `navigation` 过去。
2. 加 **「🚁 呼叫无人机查看」** 按钮 → 机器人 `wave_hand_ctrl` 举手 + 语音"请起飞查看" + 控制台弹提示。
3. 规则最小版：**机器人低电 / `alarm` / 到位** → 弹提示（+可选手机推送）。
> 这三步纯软件、不动硬件就能演示"空地联动"闭环。第 2 步还能直接录成官网 demo。

## 五、若要"真自动联动"
需把无人机换成**行业机（如 Matrice/Mavic 3E）+ DJI 上云 API / PSDK**，才能程序下发航线、读遥测 → 那时可实现"机器人报点→无人机自动飞过去回传→机器人跟进"的全自动闭环。当前 RM330 消费级遥控器做不到。
