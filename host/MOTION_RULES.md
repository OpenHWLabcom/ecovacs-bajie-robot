# 机械臂防抖 / 安全运动规则（2026-10-20 管理员定）

> 所有真机动作（按钮、脚本、训练、Skill）都必须遵守；新增动作入口先对照本文件。

## 1. 大范围 / 姿态切换（必须）
1. 先切 **慢速模式**：`vmax=0.8, amax=3.0, vmin=0.15`。
2. **先检查路径**：用 `joints_bridge.path_safe(cur, target, lift)` 对 当前→目标 直线插值做碰撞检查。
   - 路径离柱 **≥2cm** 且目标本身不碰柱 → **直接走目标**（不再插侧摆A）。
   - 路径会进入立柱 2cm 内 → 才先走 **侧摆 A**：`[1.1, 1.2, 2.0, 0, -0.8, 0]`，让大臂远离立柱。
3. **等到位**：轮询 `/joints`，与目标最大关节误差 **< 0.15 rad**；超时 25s 未到 → **中止**，不叠加下一个目标。
4. 再走目标姿态（如抓取准备位 `[0.186, 2.694, 2.150, -0.285, -1.065, 0]`）。
5. 目标到位后再恢复标准模式（`vmax=2.0, amax=6.0`）。

**禁止**：标准速度直接 `/jog` 到远目标；**路径检查不安全时**跳过侧摆 A；连续叠加多个未到位目标。

## 2. 轨迹形状
- 用 `smoothtrack` 的 S 曲线 / `FollowJointTrajectory`，不要瞬间改目标。
- 启动/切换段必须做 **位置 + 速度双斜坡**：从当前姿态渐变到目标，至少 **0.9 秒 / 30 个轨迹点**；首点速度 = 0。

## 3. 定点头（爪尖定点）
- 动作 = 机械臂**绕固定的爪尖转圈**：爪尖世界坐标不变，允许姿态小幅变化。
- **爪头可在 45° 夹角内运动，但不得翻转**（保护夹爪上方的相机）：工具轴相对起始方向 **≤45°**，绕工具轴滚转 **≤45°**；找不到构型时**继续寻找、不要自动停止**。
- 候选构型让 J1/J2/J3 负责绕圈、J4/J5/J6 只做小修正；实现见 `arm3d.html` 的 `HEADFIX_MAX_TILT / HEADFIX_MAX_ROLL / headFixOrient()`。
- 禁止 6 个点（~0.18s）硬切到目标；这是 2026-10-20 波浪启动抖动的原因。
- 波浪模式：启动走上述 0.9s 斜坡；默认幅度 `damp=0.7`，不要突然全幅启动。

## 3. 执行前检查
- 读取 `/joints`：`status=ok`，`rad` 6 维完整；必要时看 `lift`。
- 确认当前不在 `demo`/限位检测/其他动作中；机器人不 busy。
- 升降/姿态与目标匹配；工作空间内无人、无遮挡。
- 夹爪状态明确（开 0.50 / 合 0.185 / 全闭 0.0），不要半开不确定状态起步。

## 4. 夹爪 / 升降
- 夹爪：走 `/grip` 快速通道（常驻 smoothtrack），滑杆拖动自动下发；不要每次走 SSH `set_grip.py`。
- 升降：走 `voice_server` → adb forward 的 `robot_height_ctrl`；不要高频重复发同一目标，等 `lift` 反馈。
- 升降/夹爪动作前，确认不会碰到桌面/书本/立柱。

## 5. 异常处理
- 出现抖动、异响、卡滞：立即停止（`stop`），不要继续叠目标。
- 检查当前姿态与目标差值；必要时先回侧摆 A、降速、再重试。
- 连续两次失败 → 停下来检查机械/限位/负载，不要自动重试。

## 6. 代码入口（当前）
- `index.html`：`goReadyPose()`（慢速 → 侧摆A → 等待 → 目标 → 恢复）
- `arm3d.html`：`bReady.onclick`（同一安全序列）
- `smoothtrack.py`：`wave_seg()` 启动 0.9s 位置/速度斜坡
- `joints_bridge.py`：`/jog` 流式目标、`/grip` 快速夹爪
- `picksvc.py` / `grasp2.py`：仍按 `GRASP_RULES.md` 的侧摆 A / 限位规则
